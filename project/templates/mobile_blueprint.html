Auth & CSRF Setup

Django session auth. Every POST/DELETE needs a CSRF token; every request needs the sessionid cookie. Use a persistent cookie jar.
Flow
1. POST /auth/login/ → Django sets:
     sessionid   — identifies the session (store in cookie jar)
     csrftoken   — CSRF protection token

2. Extract csrftoken value.

3. Every POST / DELETE must include:
     X-CSRFToken: <csrftoken value>

4. Enable persistent cookie jar so sessionid is
   sent automatically on every request.
Common headers (every request)
Cookie: sessionid=<val>; csrftoken=<val>
X-CSRFToken: <val>        // POST / DELETE only
Accept: application/json  // always — returns JSON instead of HTML

1. Auth

Login

POST /auth/login/
Request — application/x-www-form-urlencoded
email=user@example.com
password=secret
Success
HTTP 302 — check Location header or catch redirect
Error
HTTP 200 with error in HTML — check for .error or re-login

Register

POST /auth/register/
Request — application/x-www-form-urlencoded
email=user@example.com
password=secret
password2=secret
plan=free
Note
Always register with plan=free. Upgrade via /billing/checkout/.

Forgot password

BROWSER {{ base_url }}/auth/forgot-password/ 
Open in system browser — reset flow handled server-side.

Logout

POST /auth/logout/
{# ── 2. Upload ───────────────────────────────────────────────────────── #}

2. Upload

Check key availability

GET /check-key/?key=<key>&ns=<f|c> ns=f file · ns=c clipboard 
{ "available": true,  "ns": "f", "key": "my-key" }
{ "available": false, "reserved": true, "ns": "f", "key": "save" }
Tip
Debounce ~300 ms. Show green tick / red cross inline.

Upload file — 3 steps

Files go directly to Backblaze B2. Step 1 gets a presigned URL, step 2 PUTs to B2, step 3 registers the drop.
POST /upload/prepare/ Step 1
Request — application/json
{ "filename": "photo.jpg", "size": 1048576,
  "content_type": "image/jpeg", "ns": "f",
  "key": "my-key" }
Response
{ "presigned_url": "https://…", "key": "my-key",
  "ns": "f", "expires_in": 3600 }
PUT <presigned_url> Step 2 — direct to B2, no auth headers 
Headers: Content-Type: image/jpeg
Body:    raw file bytes
POST /upload/confirm/ Step 3
Request — application/json
{ "key": "my-key", "ns": "f", "filename": "photo.jpg",
  "burn": false, "password": "" }
Response
{ "key": "my-key", "url": "/f/my-key/", "burn": false,
  "password_protected": false }

Upload text (clipboard drop)

POST /save/
Request — multipart/form-data
key=my-key          // optional
content=hello world
expiry_days=7       // paid only
password=secret     // paid only
Response
{ "key": "abc123", "url": "/abc123/" }

UX patterns
Link box       — monospace, accent colour, tap-to-copy
Drop card      — key + type icon + expiry + long-press actions
File drop      — filename + human-readable size
Text drop      — scrollable preview
Plan badge     — free / starter / pro chip
Upload zone    — dashed border, tap or share sheet
Copy snackbar  — "Copied!" 2 s, icon → checkmark

Paid features  — greyed out + Upgrade nudge for free users
