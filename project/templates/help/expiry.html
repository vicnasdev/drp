key expiry

Keys expire, not files. Every key has an expires_at timestamp set at upload time based on your plan. When a key expires, the URL stops working.

Expiry is set once at upload time. Guest and free keys use the plan maximum automatically. Paid users can choose any duration up to their plan maximum via the web expiry selector or the CLI --expires flag.

what happens when a key expires

When someone visits an expired key's URL, the server returns 410 Gone and deletes the underlying content (including its B2 object for file uploads). A background cleanup management command also sweeps for expired keys periodically.

claiming guest files

If you create files as a guest before signing up, they're tracked by a browser cookie. When you register or log in, those files are automatically claimed — transferred to your account and extended to free-tier lifetimes. This happens once per session cookie.
