use cases

🔐 burn-after-reading secrets

$ drp up "s3cr3t-api-key" --burn --password 🔑 password: •••••••• ✓ https://drp.dev/a1b2c3/ # recipient opens link → enters password → sees secret → drop is destroyed

One view, then gone. Great for API keys, passwords, and tokens.

📋 clipboard sync across devices

# on laptop $ echo "meeting notes..." | drp up ✓ https://drp.dev/x9y8z7/ # on phone / other machine $ drp get x9y8z7 meeting notes...

Pipe anything through drp. Copy on one device, paste on another.

📎 quick file sharing

$ drp up report.pdf --expiry 7d ✓ https://drp.dev/f/rpt42/ (7 days) $ drp up screenshot.png --public ✓ https://drp.dev/f/scr01/ (public)

Upload any file up to your plan's limit. Get a shareable link instantly.

📁 collections

$ drp collection create "project-docs" ✓ collection #4 created $ drp up api-spec.yaml --collection 4 ✓ added to project-docs $ drp collection list 4 api-spec.yaml f/abc12 readme.md def34

Group related drops together. Share entire collections.
